# Retailer link assets

`public/images/retailers/the-good-guys.png` is the original 130 × 130 PNG supplied
for The Good Guys Australia campaign (`1101l4116`) in Partnerize. The participating
campaign and original image were inspected in the signed-in account on 10 October 2026.

Source: https://console.partnerize.com/assets/icons/campaigns/1101l4116-1.png

The file is stored unaltered and displayed at 44 × 44 CSS pixels, including its
original white margin. It identifies the retailer on the existing approved product
affiliate links; it does not replace those tracked destinations with a homepage link.

Amazon uses a plain-text retailer label in the site's gold. This is not a recreated
or recoloured Amazon logo. Official Amazon artwork must be supplied through the
applicable programme and kept unaltered:
https://affiliate-program.amazon.com.au/help/operating/policies
